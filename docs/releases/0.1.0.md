# bitet 0.1.0

First release candidate of the Rust Varint + ZigZag library and companion Lean 4 package.

- Unsigned 32/64-bit base-128 varints and signed ZigZag mappings.
- Canonical and explicitly selected bounded noncanonical decoding.
- Prefix/exact decoding, fixed storage, caller buffers and incremental decoders.
- Zero runtime dependencies, no_std, no heap allocation and no unsafe library code.
- Exact errors/consumption counts, atomic short-buffer failure and suffix preservation.
- Eighteen formal obligations, including shortest length, canonical uniqueness,
  streaming equivalence and source-level correspondence to the packaged Rust.

The encoder exposes a bounded ten-byte view when caller capacity permits. The
bitet Apple M5 matched comparison reduced full-width u64 encoding time by
about 52% and large traversal by about 41%. Results depend on distribution and host;
the versioned benchmark reports retain samples and scope. Runtime optimality is
not a theorem.

MSRV: Rust 1.88.0. License: MIT. API examples are in README.md and `examples/`.

Formal scope is the pinned aarch64 source-extraction profile. Host/WASI execution
and RISC-V compilation provide additional evidence; compiler correctness and
cross-platform machine-code correctness are outside the formal boundary.

Release assets are the `.crate`, Lean source archive, evidence archive, verification
sidecar, and SHA256SUMS. Rust and Lean ship together at the same version.

This document describes the prepared candidate. Registry upload, public repository
and tag status are recorded by the publication step; preparation does not publish.
